# Record Room

3D vinyl player and listening space for Mac; iPad variant also found.

## Download

[Download source ZIP](https://github.com/eire360/record-room/archive/refs/heads/main.zip)

## Setup

Requires an Apple Silicon Mac with macOS 14 or later and Apple developer command-line tools.

```sh
./build.sh
open "Build.noindex/Record Room.app"
```

Open Music or Spotify and use Connect music in Record Room. Allow Music/Spotify automation when macOS asks.

## Controls

Use the app controls to play/pause, switch tracks, change the scene and browse previous albums.
